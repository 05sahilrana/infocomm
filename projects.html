Cell-free Massive MIMO

Cell-free massive MIMO (CF-mMIMO) is a distributed wireless technology that removes the fixed cell boundaries of traditional cellular networks.

A large number of geographically distributed, low-power access points jointly serve all users on the same time–frequency resources under centralized coordination.

Massive MIMO Communication Networks

Massive MIMO uses a large number of antennas at base stations to substantially improve spectral efficiency, reliability and throughput.

It enables beamforming and spatial multiplexing, and is a key technology for 5G and beyond.

Wireless Powered Communication Networks (WPCN)

WPCNs let wireless devices harvest energy from radio-frequency signals, so energy-constrained devices can run without battery replacement.

This paradigm is especially useful for IoT sensors and wireless sensor networks.

Network Coding and Information Theory

Network information theory studies the fundamental limits of information flow in networks. Network coding lets intermediate nodes combine data instead of simply forwarding it.

This approach achieves capacity bounds in many network settings.

Intelligent Reflecting Surfaces (IRS)

IRS technology improves wireless performance by reconfiguring the propagation environment with programmable reflecting elements.

It enables passive beamforming, improving coverage, capacity and energy efficiency.

Backscatter Communication

Backscatter communication lets ultra-low-power devices send data by reflecting existing RF signals instead of generating their own carrier.

This makes it well suited to battery-free IoT and sensing applications.
